# OpenTAS64

**Open-source tools for Nintendo 64 emulation and Tool-Assisted Speedrunning.**

OpenTAS64 focuses on developing tools that improve the experience of Nintendo 64 emulation and Tool-Assisted Speedrunning (TAS).

Our goal is to build useful, accessible and reliable software for players, developers and TAS enthusiasts.

## Projects

- **[OpenTAS64](https://github.com/OpenTAS64/OpenTAS64)** — Tools for Tool-Assisted Speedrunning with Nintendo 64 emulation.
